# 🌱 EcoQuest

> **EcoQuest: Sustainable Future** is a browser-based environmental city simulation game where players redesign and sustainably develop **Visakhapatnam (Vizag)** while balancing environmental, economic, and social systems.

---

## 📖 About

EcoQuest is an educational strategy simulation that teaches sustainable urban planning through interactive gameplay.

Players take the role of a city planner responsible for transforming Visakhapatnam into a greener, healthier, and more sustainable city.

Every decision has long-term consequences on:

- 🌍 Environment
- 💧 Water Resources
- 🌳 Forests
- 🐾 Wildlife
- 👥 Citizens
- 💰 Economy
- ⚡ Renewable Energy
- 😊 Public Happiness

The game focuses on learning sustainability through simulation rather than quizzes or lectures.

---

# 🎮 Features

- 🏙️ Build and expand your city
- 🌱 Restore forests and biodiversity
- 🌊 Manage rivers, lakes, and groundwater
- ☀️ Invest in renewable energy
- 🌦️ Dynamic weather and climate simulation
- 💰 Balance the city economy
- 👨‍👩‍👧‍👦 Citizen happiness and population simulation
- 🎯 Environmental missions and challenges
- 📊 Real-time environmental statistics
- 🌍 Inspired by the city of Visakhapatnam

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Kishi106/EcoQuest.git
```

Navigate into the project:

```bash
cd EcoQuest
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
