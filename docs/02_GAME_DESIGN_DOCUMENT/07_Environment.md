---

# 1. Purpose

The Environment System measures the ecological health of the city.

It integrates information from forests, wildlife, water, climate, pollution, waste management, renewable energy, and land use into a single environmental simulation.

Every player decision influences the environment.

---

# 2. Objectives

The Environment System shall:

- Simulate ecosystem health.
- Track pollution.
- Measure biodiversity.
- Calculate sustainability.
- Reward environmentally responsible decisions.
- Penalize unsustainable development.
